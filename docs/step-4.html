Room + Repository + 시즌 프리페치

목표 시즌 전체를 로컬 SSOT로 프리페치해, 날짜 조회를 네트워크 없이 로컬 쿼리로 처리한다.

선행 조건 Step 3 매퍼.

세부 단계

  1. DS-030 Entity/DAO/Database§6
    • §6 엔티티 표대로. schema export 켜기
    • 점수는 InningRunEntity로 정규화(스칼라 아님)
  2. DS-031 시즌 프리페치 워커§3.2
    • next/last 페이지 순회, 빈 배열까지, 최대 60페이지
    • leagueDate는 Asia/Seoul로 변환 저장 (§3.2)
  3. DS-032 GamesRepository§6
    • observeByDate(LocalDate)는 Room에서 읽기
    • refresh*는 네트워크 → 트랜잭션 upsert
  4. DS-033 쓰기 최적화§6
    • changeTimestamp 동일 시 DB 쓰기 스킵
    • single-flight, DataFreshness 상태
  5. DS-034 통합 테스트§9
